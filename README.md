# ScentGen Project Page

This repository contains the project page for:

**ScentGen: Hierarchical Multimodal Olfactory Semantic Modeling for Molecular Odor Description Generation**

The page is adapted from the original MA-Bench GitHub Pages template and has been updated with the ScentGen paper content, including:

- task motivation and abstract;
- MOD dataset introduction;
- ScentGen framework overview;
- quantitative and qualitative results;
- paper PDF and figure assets.
